# Labels PDF API

Модуль печати этикеток доступен через аутентифицированный JSON API. Веб-вкладка `/labels`
только показывает список предустановленных шаблонов; данные для PDF передаются в API.

## Создать PDF

```http
POST /api/labels/pdf
Content-Type: application/json
```

Запрос выполняется в пользовательской сессии приложения. Если сессии нет, API вернет
`401` с `login_required: true`.

### Входные поля

| Поле | Поддерживаемые ключи | Обязательно | Описание |
| --- | --- | --- | --- |
| Название шаблона | `template`, `template_name`, `название_шаблона`, `Название шаблона` | нет | `SRad`, `Simple`, `Medium`. По умолчанию `SRad`. |
| Наименование | `item_name`, `name`, `наименование`, `Наименование` | нет | Название товара на этикетке. |
| WB barcode | `wb_barcode`, `WB barcode`, `wb barcode` | да | WB штрихкод, печатается как Code128. |
| Артикул | `vendor_code`, `article`, `артикул`, `Артикул` | нет | Артикул продавца. |
| Размер | `size`, `размер`, `Размер` | нет | Размер товара. |
| Цвет | `color`, `цвет`, `Цвет` | нет | Цвет товара. |
| Состав | `composition`, `состав`, `Состав` | нет | Состав изделия. |
| Поставщик | `supplier_name`, `supplier`, `поставщик`, `Поставщик` | нет | Название поставщика. |
| Дата производства | `production_date`, `manufacture_date`, `дата_производства`, `Дата производства` | нет | Дата производства текстом. |
| Страна производства | `country_of_origin`, `country`, `страна_производства`, `Страна производства` | нет | Страна производства. |
| Комплектность | `note_text`, `completeness`, `комплектность`, `Комплектность` | нет | Текст для этикетки комплектности. |
| Адрес поставщика | `supplier_address`, `address`, `адрес_поставщика`, `Адрес поставщика` | нет | Адрес поставщика. |
| Коды ЧЗ | `mark_codes`, `codes`, `chz_codes`, `коды_чз`, `Коды ЧЗ` | да для `SRad`, `Simple`, `Medium` | Массив кодов ЧЗ или многострочная строка. Один код ЧЗ создает один комплект этикеток. |

Дополнительно поддерживается `brand`, `бренд`, `Бренд`.

### Пример запроса

```json
{
  "Название шаблона": "SRad",
  "Наименование": "Спортивный костюм",
  "WB barcode": "2049271462634",
  "Артикул": "cv_nk_blue_smr",
  "Размер": "38",
  "Цвет": "голубой",
  "Состав": "Хлопок 50%; Поликорбонат 50%",
  "Поставщик": "ОсОО \"ЭмирЛайн\"",
  "Дата производства": "01.06.2026",
  "Страна производства": "Кыргызстан",
  "Комплектность": "Худи-1шт, Брюки-1шт",
  "Адрес поставщика": "КР, г.Бишкек, ул. Пыльная и грязная, д. 35",
  "Коды ЧЗ": [
    "0104709055620664215YudSpca<mc9X\u001d91EE12\u001d92AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"
  ]
}
```

### Ответ

```json
{
  "ok": true,
  "download_url": "http://localhost:8000/api/labels/pdf/8b2d7a2f0c6c4ef8b6c3b4b3d0e4f7a1",
  "file_name": "labels_8b2d7a2f_58x40.pdf",
  "labels_count": 1,
  "pages_count": 4,
  "template": "srad"
}
```

`labels_count` показывает количество комплектов, то есть количество кодов ЧЗ. `pages_count`
показывает количество страниц PDF:

- `SRad`: 4 страницы на один код ЧЗ;
- `Medium`: 3 страницы на один код ЧЗ;
- `Simple`: 2 страницы на один код ЧЗ.

## Скачать PDF

```http
GET /api/labels/pdf/{file_id}
```

Возвращает PDF-файл текущего пользователя. Чужие или неизвестные `file_id` возвращают `404`.

## Валидация печати

- PDF всегда создается в формате 58x40 мм.
- В каждом шаблоне сохраняется пустой зазор 3 мм по сторонам.
- WB barcode валидируется как непустой печатный ASCII и печатается в Code128.
- Код ЧЗ валидируется как GS1 payload: `AI 01` с корректной контрольной цифрой GTIN-14,
  затем `AI 21`, а также проверочные поля `AI 91`/`AI 92` или `AI 93`.
- GS-разделитель можно передавать как реальный символ `ASCII 29`, `\u001d`, `\x1d`,
  `<GS>`, `{GS}`, `[GS]` или `␝`.

## Типовые ошибки

| HTTP | Причина |
| --- | --- |
| `400` | Тело запроса не JSON-объект. |
| `400` | Для выбранного шаблона нет ни одного кода ЧЗ. |
| `400` | WB barcode пустой, слишком длинный или содержит непечатные символы. |
| `400` | Код ЧЗ не проходит GS1/GTIN/проверочные поля. |
| `401` | Пользователь не авторизован в веб-приложении. |
| `404` | PDF с таким `file_id` не найден для текущего пользователя. |
